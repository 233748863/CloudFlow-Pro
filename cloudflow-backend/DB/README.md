# 数据库初始化指南

本目录包含 CloudFlow Pro 项目的数据库初始化脚本。

## 🚀 推荐初始化方式 (Production Ready)

对于新部署或重置环境，建议直接使用全量合并脚本，它包含了所有 Schema、索引、初始数据以及各模块（工作流、通知、文件）的表结构。

**执行文件**: `cloudflow_full_init.sql`

```bash
mysql -u root -p cloud_flow_db < cloudflow_full_init.sql
```

## 📂 分步脚本说明

如果您需要了解数据库结构的演进，或者需要单独修复某个模块，可以参考以下分步脚本：

| 脚本文件 | 说明 |
| :--- | :--- |
| **01_schema.sql** | RBAC 基础权限模块（用户、角色、部门、菜单） |
| **02_test_data.sql** | 预置测试数据（默认账号、部门结构） |
| **03_workflow_engine.sql** | 工作流引擎核心表结构 |
| **04_nacos_config.sql** | Nacos 配置中心初始化数据 (可选) |
| **05_init_data.sql** | 系统基础参数与字典数据 |
| **06_add_indexes.sql** | 生产环境性能优化索引 |
| **07_upgrade_history.sql** | 历史版本升级记录表 |
| **08_notification.sql** | 消息通知模块 (站内信、邮件配置) |
| **09_file_module.sql** | 文件存储模块 (OSS/本地存储配置) |

## ⚠️ 注意事项

1. **MySQL 版本**: 推荐 MySQL 8.0+。
2. **字符集**: 脚本默认使用 `utf8mb4`。
3. **Nacos 配置**: 如果使用 `04_nacos_config.sql`，请确保 Nacos 处于运行状态并配置了正确的数据库连接，或者手动在 Nacos 控制台导入。
