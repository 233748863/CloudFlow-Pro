## 方案概述

### 架构特点

- ✅ **页面化管理**：管理员可在系统配置页面动态修改验证码配置
- ✅ **无需重启**：配置变更实时生效，通过 Redis 缓存同步
- ✅ **租户隔离**：支持全局配置和租户级配置
- ✅ **灵活切换**：通过修改配置项即可切换验证码方案

### 2. 配置属性类

`CaptchaProperties.java`：从 sys_config 表动态加载配置

```java
@Slf4j
@Data
@Component
public class CaptchaProperties {
    @Autowired(required = false)
    private SysConfigHelper sysConfigHelper;
    
    private String type = "aj-captcha";
    private boolean enabled = true;
    private int expireSeconds = 120;
    private String ajType = "blockPuzzle";
    private double ajTolerance = 0.05;
    private String ajWatermark = "cloudflow.com";
    private String tencentAppId = "";
    private String tencentSecretKey = "";
    
    @PostConstruct
    public void loadFromSysConfig() {
        if (sysConfigHelper == null) return;
        type = sysConfigHelper.getGlobalValue("sys.captcha.type", "aj-captcha");
        enabled = sysConfigHelper.getGlobalBoolean("sys.captcha.enabled", true);
        // ... 加载其他配置
    }
    
    public void refresh() { loadFromSysConfig(); }
}
```

### 3. 策略服务

`CaptchaStrategyService.java`：根据配置动态选择方案

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class CaptchaStrategyService {
    private final CaptchaProperties captchaProperties;
    private final CaptchaService ajCaptchaService;
    private final TencentCaptchaService tencentCaptchaService;
    
    public boolean verify(String captchaVerification, String ticket, String randStr, HttpServletRequest request) {
        if (!captchaProperties.isEnabled()) return true;
        
        if ("tencent".equals(captchaProperties.getType())) {
            return tencentCaptchaService.verifyCaptcha(ticket, randStr, getClientIp(request));
        } else {
            CaptchaVO vo = new CaptchaVO();
            vo.setCaptchaVerification(captchaVerification);
            return ajCaptchaService.verification(vo).isSuccess();
        }
    }
    
    private String getClientIp(HttpServletRequest request) {
        String ip = request.getHeader("X-Forwarded-For");
        return (ip == null || ip.isEmpty()) ? request.getRemoteAddr() : ip;
    }
}
```

### 4. 登录接口

```java
@PostMapping("/login")
public R<LoginResponse> login(@RequestBody LoginRequest req, HttpServletRequest request) {
    // 验证验证码
    if (!captchaStrategyService.verify(req.getCaptchaVerification(), req.getTicket(), req.getRandStr(), request)) {
        return R.fail("验证码错误");
    }
    // 执行登录
    return R.ok(authService.login(req.getUsername(), req.getPassword()));
}
```

## 前端集成

### 1. 安装依赖

```bash
npm install @anji-plus/captcha --save
```

### 2. AJ-Captcha 组件

`AjCaptcha.tsx`：

```tsx
import React, { useRef, useImperativeHandle, forwardRef, useEffect } from 'react';

export interface AjCaptchaRef {
  show: () => void;
}

const AjCaptcha = forwardRef<AjCaptchaRef, { onSuccess: (token: string) => void }>(
  ({ onSuccess }, ref) => {
    const captchaRef = useRef<any>(null);

    useImperativeHandle(ref, () => ({
      show: () => captchaRef.current?.show(),
    }));

    useEffect(() => {
      import('@anji-plus/captcha').then((module) => {
        captchaRef.current = new module.default({
          getUrl: '/api/auth/captcha/get',
          checkUrl: '/api/auth/captcha/check',
          success: (params: any) => onSuccess(params.captchaVerification),
        });
      });
    }, [onSuccess]);

    return null;
  }
);

export default AjCaptcha;
```

### 3. 登录页面使用

```tsx
const LoginPage = () => {
  const captchaRef = useRef<AjCaptchaRef>(null);
  
  const handleSubmit = () => {
    captchaRef.current?.show();
  };
  
  const handleCaptchaSuccess = async (token: string) => {
    await login({ username, password, captchaVerification: token });
  };
  
  return (
    <>
      <Button onClick={handleSubmit}>登录</Button>
      <AjCaptcha ref={captchaRef} onSuccess={handleCaptchaSuccess} />
    </>
  );
};
```

## 配置管理界面

### 在系统配置页面管理

管理员可在 **系统管理 > 系统配置** 页面修改验证码配置：

#### 切换到腾讯云验证码

1. 找到配置项 `sys.captcha.type`
2. 修改值为 `tencent`
3. 配置 `sys.captcha.tencent.appid` 和 `sys.captcha.tencent.secretkey`
4. 保存后立即生效（无需重启）

#### 调整验证码参数

- **容错范围**：修改 `sys.captcha.aj.tolerance`（0.01-0.1，越大越容易通过）
- **有效期**：修改 `sys.captcha.expire.seconds`（建议60-300秒）
- **禁用验证码**：修改 `sys.captcha.enabled` 为 `false`

### 配置变更流程

```
管理员修改配置 → SysConfigService 更新数据库 → 更新 Redis 缓存 → CaptchaProperties 自动刷新 → 立即生效
```

## 常见问题

### Q1: 验证码图片不显示？

**原因**：Redis 未启动或连接失败

**解决**：
```bash
redis-cli ping  # 检查 Redis
tail -f logs/cloudflow-auth.log | grep captcha  # 查看日志
```

### Q2: 切换方案后不生效？

**原因**：配置未刷新

**解决**：
1. 检查 Redis 缓存：`redis-cli GET "sys:config:global:sys.captcha.type"`
2. 手动刷新：重启 cloudflow-auth 服务
3. 检查 SysConfigHelper 是否正确注入

### Q3: 腾讯云验证码调用失败？

**原因**：AppId 或 SecretKey 配置错误

**解决**：
1. 登录腾讯云控制台验证配置
2. 检查网络连通性：`curl https://captcha.tencentcloudapi.com`
3. 查看详细错误日志

### Q4: 如何临时禁用验证码？

在系统配置中修改 `sys.captcha.enabled` 为 `false`，立即生效。

### Q5: 验证码容错范围如何调整？

修改 `sys.captcha.aj.tolerance`：
- `0.01`：非常严格
- `0.05`：默认（推荐）
- `0.1`：宽松
