## 布局与交互

```text
+---------------------------------------------+
| 现有卡片标题                 [查看数据表]     |
| 图表 / 骨架屏 / 无数据                       |
| 可见图例：系列名称；风险同时显示状态文字       |
+---------------------------------------------+
| 切换后：同一数据的表头、数值及可键盘操作入口   |
|                           [查看图表]         |
+---------------------------------------------+
```

沿用现有 CSS 字体、间距、边框及亮暗色变量。工作负载环图保留居中总数与右侧明细，数据表按钮放在卡片标题内，避免挤压 156px 环图。普通预设把切换按钮放在图表上方；移动端按钮至少 44px，表格只在自身容器横向滚动。图表过渡 200ms，响应系统减少动画设置；数据表切换不做离场动画。加载使用 Skeleton，空态使用 EmptyState，指标卡复用 StatCard。
