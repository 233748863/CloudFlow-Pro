# A1代码生成器当前产物复核

核验日期：2026-09-16。已修复内部模板缺少服务接口import、目录链接绕过敏感目录保护、字段配置导入失败、同步覆盖手工配置、改名字段缺少数据库映射及页面覆盖确认范围不一致六项实际缺陷。四类模板8组代表配置、93项边界及44项真实页面检查复跑通过；新增生成菜单23项数据库检查、39项真实菜单页面检查通过。真实结构导入583项断言、35份Java生成编译和供应商真实读写再次通过，7组产物查询6组通过、验证码表1组失败。具体表设计与固定审计模板冲突待确认，不据此声明A1或全量PRD完成。

## 1. 根因与修复

`cloudflow-backend/cloudflow-auth/src/main/resources/codegen/java/controller.java.vm`原先用`#if(!$innerTemplate)`包住服务接口import，但内部模板仍生成对应的构造器依赖字段。缺失类型的两个实测产物是`IGeneratedInnerBasicService`和`IGeneratedInnerFullService`，错误分别出现在生成Controller的第25行字段声明及第22行构造器注解处理位置。

修复移除这处import条件，四类模板均引用自身服务接口；保留`@Inner`、内部路由以及不生成外部权限菜单的约束。未手改任何生成的Java文件，未改变业务接口权限或员工授权。

目录链接 = 将一个目录路径映射到另一实际目录的文件系统连接。`SysCodegenServiceImpl.resolveSafeTarget`原先只对表面路径检查敏感目录，指向项目内`DB`的链接可绕过检查；对合法内部目录别名又可能使用表面根路径比较而错误拒绝。本轮同时取得根目录及最近已存在祖先的真实路径，检查实际路径仍在真实根目录内，并再次检查敏感目录；表面路径的原有检查保留。修复沿用相对路径第一个目录段的敏感目录规则，不宣称任意深层目录、并发换链或Linux符号链接已验收。
