# A3内部任务身份验证实施复核

用户批准的内部任务身份验证已完成本阶段实施与验证：独立签名保护执行、状态查询、处理器上报、执行结果回报及后台业务登记；保留原来源服务白名单。五个服务均完成自有环境重启且健康，正式环境未修改。

## 行为和实现

五个逻辑服务分别使用32字节随机凭据。调度端持有五方校验凭据，工作服务仅配置自己的凭据及调度端校验凭据；仓库只含环境变量引用，自有主副本由当前Windows账户加密，配置文件ACL仅允许当前账户与SYSTEM。缺少凭据或长度、编码错误时拒绝启动。

HMAC-SHA256签名绑定方法、原始路径及查询、来源和接收服务、租户、用户编号、Authorization/Cookie摘要、原始请求体摘要、时间与16字节随机编号。验签、请求体比对和Redis原子登记均在控制器前完成；时间窗为前后300秒，编号记录601秒以覆盖整秒取整边界。重复请求403，Redis连接不可用503，拒绝请求不进入业务控制器。原请求体仍完整交给原控制器。

五个任务Feign客户端在最终发送时签名，保留原负载均衡客户端；业务侧RestClient对完成序列化的请求字节签名。公共InnerAspect、其他内部业务接口及SQL未改。任务模块仅补充仓库既有jakarta.servlet-api的provided声明，无新第三方库或版本。
