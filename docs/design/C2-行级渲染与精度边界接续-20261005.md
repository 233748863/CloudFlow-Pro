# C2行级渲染与精度边界接续

接续C2设计器专项，补齐原PRD的AC-3/8/9与当前版本统一验收，不新增业务规则、数据结构或依赖。本稿仅记录下一阶段核验范围，尚无新增通过数；此前B74/F46与B75/F47分别保留其完整阶段证据。

行级渲染使用当前真实FormRenderer与FormSubTable，在验证服务器内观察行组件及行内字段的实际执行次数，不向产品源码添加计数、不改表单模型。覆盖电脑及手机、普通明细及超过30行的虚拟明细；编辑一行时核对其他已挂载行，另验证主表依赖变化、行列错误变化与增删排序仍能更新，防止为减少渲染而丢失必要更新。结构行与字段内容分别记录，不能把字段未重复执行直接写成所有行组件均未执行。

精度与定义边界按原数值限制检查精确金额、SUM/COUNT/AVG、未填写与零值、舍入及最多500行，并复核服务端已有定义拒绝。已有真实十类型及实际附件结果可按相同输入复用，发生产品变更时须重新构建并完成受影响真实入口；最终核对全部12条验收与各证据的产品输入，未复验的历史范围仍明确保留。
