# H2离职结算来源冻结接线

沿用已批准设计，先实现结算事务中的来源占用、核对及释放，再接独立财务审批。提交前按员工、结算、工资、借款、假期来源顺序加锁；假期复用现有`leave:员工:假种`锁，持有至事务结束。培训追偿在同一事务占位。不增加表或菜单，不向客户端开放单独冻结接口。

提交必须已完成草稿计算及全部核定，重新核实来源集合、金额、版本及依据；不一致时整单拒绝并要求重算。工资只更新结算占位与版本，不改金额、明细或封存摘要；借款仅预约未在工资预扣的剩余本金，零余额不造还款流水；假期用原单位写FREEZE，培训只占位。保存冻结后的来源证据，供确认前核对。

退审或撤销在同一锁序释放该单占位。假期保留原FREEZE并写精确相反数量的UNFREEZE，不删除原事实；借款保留RELEASED记录，重复释放不能改变金额。再次提交使用新的冻结轮次，旧证据保留。释放不能借机修改已入账来源。
