## 0. 遵循的既有约定（实测提取）

```java
返回类型：  R<T>            // R.ok() / R.ok(data) / R.fail(msg) / R.result(boolean)
分页返回：  R<PageResult<T>>  // PageResult{rows, total, pageNum, pageSize}
分页入参：  PageQuery{pageNum=1, pageSize=10, params}
           或 @RequestParam(defaultValue="1") Integer pageNum + pageSize（如 SupplierController）
权限码：    @SaCheckPermission("{module}:{resource}:{action}")
内部接口：  @Inner，路径前缀 /inner/{module}/{business}
操作日志：  @SysLog("动作说明")   // 增删改必带
幂等：      @RepeatSubmit        // 新增必带
类级注解：  @RestController + @RequestMapping("/xxx") + @RequiredArgsConstructor
```

**权限码模块前缀只允许**：`system` / `oa` / `crm` / `hr` / `workflow`（PLAN.md 完成态约束）。本批全部落在 `system`。

## 1. A1 代码生成器（10 接口）

服务：`cloudflow-auth` · 路径前缀 `/system/codegen`

```java
@RestController
@RequestMapping("/system/codegen")
@RequiredArgsConstructor
public class SysCodegenController {

    // 查询数据库中未导入的表
    @GetMapping("/db/list")
    @SaCheckPermission("system:codegen:list")
    R<PageResult<DbTableVO>> dbTableList(String tableName, String tableComment,
                                        @RequestParam(defaultValue="1") Integer pageNum,
                                        @RequestParam(defaultValue="10") Integer pageSize);

    // 已导入表列表
    @GetMapping("/list")
    @SaCheckPermission("system:codegen:list")
    R<PageResult<SysCodegenTable>> list(SysCodegenTable query,
                                       @RequestParam(defaultValue="1") Integer pageNum,
                                       @RequestParam(defaultValue="10") Integer pageSize);

    // 表与列配置详情
    @GetMapping("/{tableId}")
    @SaCheckPermission("system:codegen:list")
    R<CodegenDetailVO> getInfo(@PathVariable Long tableId);   // CodegenDetailVO{table, columns[]}

    // 已注册 handler 无关；此处为可用模块与类型选项
    @GetMapping("/options")
    @SaCheckPermission("system:codegen:list")
    R<CodegenOptionsVO> options();   // 模块列表、tpl_category、query_type、html_type 枚举

    @SysLog("导入代码生成表结构")
    @RepeatSubmit
    @PostMapping("/import")
    @SaCheckPermission("system:codegen:import")
    R<Void> importTables(@RequestBody CodegenImportDTO dto);   // {tableNames[], moduleName}

    @SysLog("保存代码生成配置")
    @PutMapping
    @SaCheckPermission("system:codegen:edit")
    R<Void> edit(@RequestBody CodegenSaveDTO dto);   // {table, columns[]}

    @SysLog("同步代码生成表结构")
    @PostMapping("/{tableId}/sync")
    @SaCheckPermission("system:codegen:edit")
    R<Void> syncTable(@PathVariable Long tableId);

    // 预览：返回 文件相对路径 -> 文件内容
    @GetMapping("/{tableId}/preview")
    @SaCheckPermission("system:codegen:preview")
    R<Map<String, String>> preview(@PathVariable Long tableId);

    // 下载 ZIP（返回流，不包 R）
    @GetMapping("/{tableId}/download")
    @SaCheckPermission("system:codegen:generate")
    void download(@PathVariable Long tableId, HttpServletResponse response);

    @SysLog("写入生成代码到磁盘")
    @PostMapping("/{tableId}/write")
    @SaCheckPermission("system:codegen:generate")
    R<CodegenWriteResultVO> writeToDisk(@PathVariable Long tableId,
                                       @RequestBody CodegenWriteDTO dto);
    // dto: {targetRoot, confirmOverwrite}；返回 {written[], skipped[], overwritten[]}

    @SysLog("删除代码生成配置")
    @DeleteMapping("/{tableIds}")
    @SaCheckPermission("system:codegen:remove")
    R<Void> remove(@PathVariable List<Long> tableIds);
}
```

**权限码 6 个**：`system:codegen:list` / `:import` / `:edit` / `:preview` / `:generate` / `:remove`

**环境开关**：全部接口前置校验 `cloudflow.codegen.enabled`，为 false 时返回 `R.fail(403, "代码生成器已关闭")`。实现方式：类级 `@ConditionalOnProperty` 不合适（会导致 404 而非 403），改用拦截器或每方法开头校验。

## 3. A3 定时任务平台（16 接口）

### 3.1 管理面（12）—— `cloudflow-auth`
```java
@RestController @RequestMapping("/system/job") @RequiredArgsConstructor
public class SysJobController {

    @GetMapping("/list")        @SaCheckPermission("system:job:list")
    R<PageResult<SysJobVO>> list(SysJobQuery query, ...);
    // query: jobName/jobGroup/serviceName/status/triggerType

    @GetMapping("/{jobId}")     @SaCheckPermission("system:job:list")
    R<SysJobVO> getInfo(@PathVariable Long jobId);

    @GetMapping("/handlers")    @SaCheckPermission("system:job:list")
    R<List<SysJobHandlerVO>> handlers(String serviceName);
    // 返回已上报 handler，含 status(ONLINE/OFFLINE) 与 lastReportTime

    @SysLog("新增定时任务") @RepeatSubmit
    @PostMapping               @SaCheckPermission("system:job:add")
    R<Void> add(@RequestBody @Valid SysJobDTO dto);
    // 校验：handler 必须已上报；CRON 表达式合法；FIXED_* 必填 intervalMs

    @SysLog("修改定时任务")
    @PutMapping                @SaCheckPermission("system:job:edit")
    R<Void> edit(@RequestBody @Valid SysJobDTO dto);
    // 保存后立即重注册 ScheduledFuture（同进程，无需通知）

    @SysLog("删除定时任务")
    @DeleteMapping("/{jobIds}") @SaCheckPermission("system:job:remove")
    R<Void> remove(@PathVariable List<Long> jobIds);
    // critical_flag=1 的任务需 dto.confirmCritical=true 才允许删

    @SysLog("手动触发定时任务")
    @PostMapping("/{jobId}/trigger")  @SaCheckPermission("system:job:trigger")
    R<JobTriggerResultVO> trigger(@PathVariable Long jobId,
                                  @RequestBody(required=false) JobTriggerDTO dto);
    // dto.handlerParam 可临时覆盖；返回 {executeNo, accepted}

    @SysLog("启停定时任务")
    @PutMapping("/{jobId}/toggle")    @SaCheckPermission("system:job:toggle")
    R<Void> toggle(@PathVariable Long jobId, @RequestBody JobToggleDTO dto);
    // dto: {status, confirmCritical}；critical_flag=1 暂停需二次确认

    @PostMapping("/cron/validate")    @SaCheckPermission("system:job:list")
    R<CronValidateVO> validateCron(@RequestBody CronValidateDTO dto);
    // 返回 {valid, message, nextFireTimes[5]}

    @GetMapping("/log")               @SaCheckPermission("system:job:log")
    R<PageResult<SysJobLogVO>> logList(JobLogQuery query, ...);

    @GetMapping("/log/{logId}")       @SaCheckPermission("system:job:log")
    R<SysJobLogVO> logDetail(@PathVariable Long logId);   // 含完整异常栈

    @SysLog("清理定时任务日志")
    @DeleteMapping("/log/clean")      @SaCheckPermission("system:job:remove")
    R<Integer> cleanLog(@RequestBody JobLogCleanDTO dto);   // {beforeDate} 或 {keepDays}
}
```

## 5. 权限码汇总（32 个，全部落在 `system` 前缀）

| 模块 | 权限码 | 数量 |
| --- | --- | --- |
| 代码生成器 | `system:codegen:{list,import,edit,preview,generate,remove}` | 6 |
| 消息渠道 | `system:message:channel:{list,add,edit,remove}` | 4 |
| 消息模板 | `system:message:template:{list,add,edit,remove}` | 4 |
| 消息记录 | `system:message:record:{list,resend}` | 2 |
| 我的消息 | `system:message:mine:{list,read}` | 2 |
| 消息订阅 | `system:message:subscribe:{list,edit}` | 2 |
| 定时任务 | `system:job:{list,add,edit,remove,trigger,toggle,log}` | 7 |
| 节假日 | `system:holiday:{list,add,edit,remove,import,query}` | 6 |

**授权建议**（写入 `06` 种子数据）：

| 角色 | 授予 |
| --- | --- |
| 超管 | 全部 32 个 |
| 管理员 | 除 `system:codegen:*`（开发工具）外的 26 个 |
| 普通员工/其他 | 仅 `system:message:mine:*`（2）+ `system:message:subscribe:*`（2）+ `system:holiday:query`（1）= **5 个** |

> ⚠️ `system:message:mine:*` 与 `system:holiday:query` 必须授予**全部角色**，否则消息铃铛与日期选择器对普通用户不可用。

## 6. 构建期扫描合规性

按 PLAN.md 的构建期扫描规则,本批 62 个接口分类：

| 类别 | 数量 | 合规 |
| --- | --- | --- |
| `@SaCheckPermission` 外部接口 | 52 | ✅ |
| `@Inner` 内部接口 | 8 | ✅ |
| 匿名接口（短信验证码 2 个） | 2 | ✅ 需加入白名单配置 |
