# G4 应用消息实施

状态：应用文本消息及通知卡片阶段验证完成，2026-09-30。承接已批准的外部接入设计5.1、5.4及G4 FR-6，复用SYS-01持久投递、限流、重试和结果未明人工核验，不新增队列、表、列、菜单或依赖；正式企业微信联调未执行。

企业微信渠道按当前租户读取唯一配置与本地用户绑定；配置、渠道、租户、账号停用或绑定已解除时明确跳过，客户端自报外部账号不作为接收地址。已停止管理的DISABLED映射不可接收消息，OUT_OF_SCOPE沿已有账号绑定规则保留通知能力。身份凭据复用按租户、配置和版本隔离的加密缓存。每次发送只指定一个经过绑定查询的成员，禁止部门、标签或全员广播。

无详情链接时发送文本，正文合并标题后按UTF-8核对2048字节限制，超限保存失败原因；有详情链接时发送text_notice应用模板卡片，标题及摘要分别采用36字和160字的展示长度，超出以省略号显示，通过本系统HTTPS详情链接查看完整内容。链接只允许当前部署站点的普通页面，不接受登录回调、API路径、跨站地址或用户信息段。模板链接沿现有模板参数渲染；暂不生成审批按钮，待办字段权限、分派版本和持久回调属于后续已批准范围。

发送前已由统一投递进入SENDING，外部请求在事务外。明确成功必须有合法消息编号且接收人未被列为无效或无许可；凭据拒绝和明确临时拒绝交给持久投递重试，超时、断连、畸形返回或缺消息编号保存UNKNOWN。一次发送内不自动重试；禁止把HTTP成功或errcode=0单独当成成员已收到消息。

官方协议依据：2026-09-30读取`https://developer.work.weixin.qq.com/document/path/90236`，HTTP200，原始页面保存在`.cloudflow-runtime/full-prd-20260915/approved-runtime/g4-im-message-official-90236-20260930.html`。文档明确文本2048字节、无效/无许可成员列表、msgid及模板卡片格式；36/160为官方建议展示长度，本地按此生成摘要，不称厂商硬性上限。正式厂商联调仍未执行。

## 模板与接入

正式06种子为每个有效租户提供`IM_NOTICE_TEXT`和`IM_NOTICE_DETAIL`，复用`sys_message_template`、统一消息事件及原投递记录。文本要求标题和正文，详情卡片另外要求本系统详情路径；缺少必填参数不外发。种子重复执行保留管理员修改，不自动创建或启用渠道。`prepare-im-message-integration.mjs`核验隔离数据库归属后按正式种子定向加入四条模板（两个有效租户），重复执行一致，原有模板全列摘要不变。

渠道页面沿用当前租户的企业通信配置，不再要求重复填写地址和密钥；连通性测试仅验证凭据，不发送业务通知。发送记录与核验详情显示中文原因；普通员工不能维护或测试渠道。消息渠道、模板、发送记录补入手机导航，使用原权限及真实页面。
