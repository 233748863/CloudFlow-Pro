# E5 营销活动闭环全项验收映射

对应 `docs/prd/E5-CRM-02-营销活动闭环-PRD.md` 的 21 条验收。B145/F97 全部 21 条本机功能已由独立 R11、关联 R184 及统一 R1 核定通过，完整版本、终态及边界见《E5-全项统一核定-20261010.md》。下表每条对应统一结果 `Items` 中同编号的 `RequiredChecks` 和 `ExecutedChecks`；同一断言被多个需求引用时不重复相加。

| 编号 | 业务要求 | 已通过的实际证据 |
| --- | --- | --- |
| AC-1 | 活动预算与实际成本 | 实际新增、编辑、并发版本保护及重新读取；金额按分核对 |
| AC-2 | 两种目标名单来源 | 手工名单与条件名单分别保存，按真实线索、客户、联系人及权限范围核对 |
| AC-3 | 受众合并与排除 | 并集去重，排除名单、退订和缺失邮箱逐一生效 |
| AC-4 | 个性化邮件发送 | 本机 TLS 收件器实际接收，核对转义后的占位符与收件人 |
| AC-5 | 测试邮件 | 仅指定测试邮箱收到，test_flag=1 且不进入正式统计 |
| AC-6 | 定时发送 | 真实系统时间到期后由定时任务发送，到期前保持未发送 |
| AC-7 | 发送取消 | 分批发送时取消，未发送收件人保持停止 |
| AC-8 | 发送限速 | 实际渠道分钟额度与跨分钟继续发送，不写入或清理 Redis 限流键 |
| AC-9 | 打开追踪 | 真实邮件链接触发，重复与并发仅形成一次有效观察 |
| AC-10 | 点击追踪 | 真实链接正确跳转并去重计数 |
| AC-11 | 重定向保护 | 非许可地址与额外重定向参数拒绝 |
| AC-12 | 令牌及限流 | 43 字符随机用途令牌、伪造与错用途拒绝、自然分钟内真实限流 |
| AC-13 | 有效退订 | GET 仅读取确认页、POST 真实退订且立即保存抑制状态 |
| AC-14 | 后续群发排除 | 退订后的新名单与实际投递均排除该对象 |
| AC-15 | 活动来源传递 | 真实活动线索经资质判断转为客户与商机，来源编号完整继承 |
| AC-16 | 实际回款收益 | 真实赢单、合同、应收、逐笔回款与全额冲正，每一步重算并核对收入和投入产出比 |
| AC-17 | 归因时间窗 | 活动开始及结束加30天边界；历史日期仅使用新建测试样本并明确记录 |
| AC-18 | 完整营销漏斗 | 发送、送达、打开、点击、线索、商机及赢单与实际事件逐项核对 |
| AC-19 | 可重算计数 | 真实日志、快照及重算结果一致，重复回调不新增有效事件 |
| AC-20 | 大名单二次确认 | 阈值、精确人数与摘要版本改变后的拒绝和有效确认 |
| AC-21 | 名单导出权限与审计 | 有权导出、本人及部门范围、拒绝导出和审计记录 |

营销日志按 12 个月保留期执行无损压缩归档，两个真实任务完成，事件唯一键、历史统计、退订抑制及迟到追踪均保持；2,112 项归档检查包含在本轮 2,567 项数据库检查内。12 张最新图片已逐张查看，原 R10 漏斗裁切失败及其修复证据保留；正式邮件商及公网部署按已约定的外部联调边界单列。
