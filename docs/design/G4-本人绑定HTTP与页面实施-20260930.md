## 接口边界

本人入口位于受保护的`/system/im/binding/mine`，读取、近期身份复核、授权、待确认和最终提交均校验对应本人权限。POST只接受严格JSON，不接受客户端本人/租户/配置/用途参数；验证精确Origin及XSRF双重提交，实际身份和提交继续要求HTTPS。新增匿名范围只有GET `/im/WECOM/binding-callback`，网关剥离旧身份，仅保留浏览器证明Cookie，不放行整个目录。

回调只通过Secure、HttpOnly、host-only、SameSite=Strict Cookie保存短期外部证明；成功/失败只返回固定页面及不含凭据的状态标记。证明不进URL、JavaScript存储或页面表单。站内最终提交再核验当前会话和双方证明；响应丢失后先刷新查询，不自动重发。页面按本人/租户/登录版本隔离，旧异步结果不得落入新身份。
