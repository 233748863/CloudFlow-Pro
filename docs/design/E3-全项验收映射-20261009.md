# E3 丢单分析与客户信用额度全项验收映射

对应 `docs/prd/E3-CRM-丢单分析与信用额度-PRD.md` 的 18 条验收。B141/F91 当前独立 R18 与统一 R1 已通过。 每条均绑定实际执行断言，证据见《E3-全项统一核定-20261010.md》。历史《E-批次E实施验收记录.md》《DE-真实验收里程碑.md》保留原执行版本。

| 编号 | 业务要求 | 实际证据 |
| --- | --- | --- |
| AC-1 | 多原因且唯一主因 | 空原因、无主因、多主因、重复、停用和其他租户原因均拒绝；有效组合真实审批通过 |
| AC-2 | 竞对、原因与金额 | 真实丢单审批后逐条核对全部原因、竞对及金额 |
| AC-3 | 数量与金额分别排名 | 两个前十排名分别排序；电脑、手机、共享总看板、键盘金额表及空态通过 |
| AC-4 | 竞对胜负比 | 多原因按商机去重，零值、实际赢单、本人/部门/全范围与其他租户排除通过 |
| AC-5 | 补充说明保存 | 审批前保留商机原状态，批准后说明和全部明细准确 |
| AC-6 | 原因及竞对维护 | 实际新增、编辑、停用、旧版本拒绝及电脑/手机重开通过 |
| AC-7 | 额度设置与审批 | 六笔实际两级审批，首次未生效、并发只建一笔、驳回保留原额度、审批期间独立放行保持通过 |
| AC-8 | 额度与占用视图 | 信用页电脑/手机、客户工作台及只读角色核对额度、占用、可用与超期金额 |
| AC-9 | 未回款占用 | 实际部分及全部回款精确到分；关闭、取消、删除、其他客户和租户不计入 |
| AC-10 | 超期应收 | 昨天/今天/明天/空日期边界及回款后即时释放核对 |
| AC-11 | 超期阻断 | 报价提交、报价转合同、客户工作台合同三个入口；金额及原状态保持，超过额度一分钱边界通过 |
| AC-12 | 警告放行并提示 | 实际提交成功、警告响应和销售页面提示，单独 PASS 不提示 |
| AC-13 | 发布即时生效 | 草稿不生效，发布后无需重启服务即可改变实际业务结果 |
| AC-14 | 回滚恢复行为 | 旧效果以新发布版本恢复，实际 BLOCK→WARN→BLOCK 逐次留痕 |
| AC-15 | 临时放行仍留痕 | 仅授权人操作、原因与到期日校验，操作者/时间和两个规则的 BYPASSED 记录通过 |
| AC-16 | 过期恢复检查 | 独立样本使用明确的前一天到期输入，恢复阻断且保留原操作者资料，撤销放行审计通过 |
| AC-17 | 命中持久记录与查询 | 连续相同结果合并；60.08→60.09→60.08 留存三条；按租户/规则/业务/单据查询最新结果，筛选在选出最新后执行，空单据、分页、双端开关及七字段可见通过；例外放行中文显示及双端实际筛选通过 |
| AC-18 | 阻断及放行审计 | 业务失败回滚后命中与审计保留；信用申请、批准、临时放行和撤销的操作者记录通过 |

命中记录表没有版本字段；规则草稿、发布与回滚版本另以真实规则版本记录核对。金额计算性能针对实际读取额度的数据库语句，严格小于 100 毫秒，未替换为整个网页请求的耗时。

全部结果来自 D 盘独立数据库、缓存、六服务与真实网页操作；原运行库 23 张表前后摘要保持。验证码配置与计数只读、邮件未外发、系统时钟未修改；历史日期输入不表述为等待现实日期经过。本轮 17 张实际页面截图已逐张查看并纳入统一核定；历史失败及诊断保留原结果；R16 业务通过、图片复核存在两处缺陷的结论分别保留。
