# G2 原文件保留策略开发记录（2026-10-17）

## 实现范围

对应 G2 PRD §5、§9-5：新增 cloudflow.import.delete-original-after-import（环境变量 CLOUDFLOW_IMPORT_DELETE_ORIGINAL_AFTER_IMPORT），值为逗号分隔的 bizType；默认空，继续原 30 天保留，不修改现有运行配置。成功或部分成功且全部行处理完成后，按业务策略删除原文件，错误文件及任务统计保留；已删除原文件通过明确的 REMOVED 引用标记，预览继续返回错误明细，原文件下载返回 404。

实际清理经 auth 内部接口，限制原有内部服务来源、操作人、租户、本次 jobLogId 及完成状态；同租户存储锁和引用计数保护共享文件。定时清理按显式租户、业务类型和 task_id 游标分页重试，单项失败不会在本轮重复空转。物理删除失败使该项事务回滚、保留引用以便后续重试；物理存储与数据库不处于同一事务，删除成功后数据库提交失败仍有原系统一致性边界，未宣称数据库故障注入通过。

页面删除原文件后显示策略提示、隐藏原文件预览表，仍允许查看错误统计和分页明细。导入结果已经提交后清理失败仅记录待重试，不改写业务成功状态。
