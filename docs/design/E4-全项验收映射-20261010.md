# E4 线索资质与客户分层全项验收映射

对应 `docs/prd/E4-CRM-04-线索资质与客户分层-PRD.md` 的 14 条验收。基线为 B141/F91；B142/F95 独立 R9 已执行全部 14 条，统一 R2 于 2026-10-10 核定通过，详见《E4-全项统一核定-20261010.md》。

| 编号 | 业务要求 | 已绑定的实际证据 |
| --- | --- | --- |
| AC-1 | 画像及资质字段可保存与查询 | 真实新建、编辑和重读；服务端控制判定及评分元数据；年营收 99999999999999.99 精确保存、电脑编辑及手机刷新重开 |
| AC-2 | 三类资质动作与判定人、时间 | 开始评估、合格、不合格的实际接口与电脑、手机表单；版本冲突和所有者、租户限制 |
| AC-3 | 不合格原因必填 | 空值、空格、501 字原因拒绝且整条线索保持；实际页面禁止无原因提交 |
| AC-4 | 仅合格线索可以转化 | 未评估、评估中、不合格均拒绝，原线索及客户、联系人、商机数量保持 |
| AC-5 | 不合格可重新评估 | 重评清除旧判定元数据，再次合格与手机办理；已转化线索拒绝重评 |
| AC-6 | 区域树增删改、拖拽和五层限制 | 实际五层树、六层拒绝、自身和后代循环拒绝、引用与子区域删除保护、页面拖拽、手机刷新和名称/编码边界 |
| AC-7 | 区域子树路径正确 | 移动前后全部后代路径、原子树排除、跨租户拒绝 |
| AC-8 | 转化字段完整传递 | 八个画像和来源字段、精确金额、客户与联系人联系方式、可选商机、手机输入 999999999999.99 元预计金额后提交及存储、来源追溯及重复转化保持 |
| AC-9 | 评分配置并正确累加 | 11 种运算符、负分及停用规则；非法规则拒绝，实际页面保存、手机刷新和重开 |
| AC-10 | 批量重算与评分排序筛选 | 实际任务入队及消费、去重、权限先验、三笔逐条核验；电脑筛选、手机批量按钮、完整线索名称可见及 44×44 像素操作按钮 |
| AC-11 | 评分保持人工资质结论 | 创建、编辑、单条和两轮实际批量重算前后逐字段比较 |
| AC-12 | 退订排除营销且保留正常业务 | 实际营销受众名单排除线索及客户；重新订阅及再次退订立即更新；退订线索仍可合格并转为客户，不发送邮件 |
| AC-13 | 漏斗与四维分布正确 | 按五类真实账号对比独立数据库聚合；电脑、手机图表和键盘数据表 |
| AC-14 | 资质与退订审计 | 实际动作的操作者、高风险标记、状态、原因及退订开关记录 |

现有库及金额组件采用 16 位总数字、2 位小数，营收上限为 99999999999999.99；商机沿用 `CrmSalesAmounts.expected` 的 12 位整数、2 位小数校验，上限为 999999999999.99，超出时转化整体回滚。保留这两个已有产品口径，并明确其与 PRD 初稿 DECIMAL(14,2) 描述的差异。不会把普通表单传入的判定人、判定时间或评分当作可信事实。

验证只使用 D 盘新建数据库、缓存和六个服务，原运行库 31 张表前后摘要须保持；验证码配置和计数仅读取，实际登录自然计数，营销仅查看名单。构建和业务验证串行，收取原入口终态后再修改文件；全部 18 张截图已实际查看并通过统一核定；539 项检查、256 次脚本请求、873 次页面请求，原业务结果不改写。AC-5 额外复用原 AC-8 分组内实际执行的转换后禁止重评断言，保留来源分组。
