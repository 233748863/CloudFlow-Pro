# 离职结算金额舍入补充

状态：2026-09-30用户已明确批准“统一四舍五入到分”，并在结算单保留计算规则。

已批准设计要求按核定规则舍入，但未明确最后不足一分钱的处理方法；现有六表也没有独立的金额舍入配置列。实现中的计算器因此要求显式提供舍入方式，未默认采用法定或企业政策。

已批准统一采用四舍五入到分（Java `RoundingMode.HALF_UP`）：0.005元记0.01元，0.004元记0.00元。工龄、月工资平均值、日薪及补偿月数保留中间精度；每条来源明细在形成入账金额时舍入，单据合计累加已经舍入的明细，不再次从展示数计算。冲正直接取原已入账金额的相反数。

通过现有`hr_final_settlement.calculation_snapshot`记录本次舍入方式、未舍入工龄分子分母、规则ID/版本与来源明细；无须新增或修改数据库列。

本次裁决解除金额舍入的实施阻塞；补偿政策及正式结算继续按已批准范围实现和验证，裁决本身不代表这些功能已交付。
