## 通用追加指令（任何时候可以补发）

**它开始跳步、直接输出代码时：**

```
停。先按我上一条消息的要求，把复述、核实、计划三件事做完。
你现在写的代码我不看。
```

**它报告文档与代码不符时（这是预期行为，鼓励它）：**

```
这个报告是对的，继续按实测结果走，不要按文档硬写。
把你发现的不符列出来，我会回写文档。
```

**它交付一段之后：**

```
这段我验证过了。下一段开始前先说明：这段有没有遗留的 TODO、
有没有你当时不确定但先按假设写了的地方。有就现在提出来。
```

**它想顺手改范围外的代码时：**

```
不要改。按提示词第六节第 7 条记录下来，我单独评估。
本批范围外的现存缺陷不在这轮处理。
```
