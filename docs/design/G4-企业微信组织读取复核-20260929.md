# G4企业微信组织读取复核

日期：2026-09-29。仅为组织读取及内存加密封装检查点；完整同步、G4全部业务和全量PRD仍未完成。本轮不把下列基础检查解释为预览、持久化、员工/部门更新或厂商联调验收。

## 1. 实现范围

- 新增`ImOrgProvider`、`WeComOrgProvider`、`WeComOrgReader`、`ImOrgTopology`、`ImOrgScope`、`ImOrgSnapshot`和`ImOrgSnapshotCodec`七份生产Java；修改`WeComHttp`唯一新增只读官方路径`/cgi-bin/agent/get`、`ImFailure`安全原因码及`ImConfigRules`共用范围校验。未新增依赖、DDL、菜单、角色授权或页面。
- 请求开始前复制本地根、远端根及主部门选择，拒绝空键/空值、重复根及大小写冲突的成员标识；读取过程中修改原请求对象不会改变快照。构造快照本身再次检查树、成员归属、重复标识、字段容量及头像地址，不能绕过读取器直接构造非法组织。
- 先核对应用ID、应用未关闭以及`allow_partys.partyid`完整部门可见范围，再列部门并逐个读取选中根的所有子部门。仅用户/标签可见不能证明完整部门权限，立即拒绝。每次成员响应都核对其部门归属，同一成员跨部门内容必须一致，所有选中归属部门均须观察到该成员。
- 部门和可见范围读取三遍，成员完整读取两遍，观察到差异即拒绝；这属于跨请求一致性检查，厂商接口没有提供原子快照版本，不能承诺并发变更期间的原子视图。部分错误、未知分页标志、缺失列表、循环父子、重复ID和非法数字均不产生快照。
- 最多100个请求根、1000个可见部门、10000个唯一成员；4分钟后不再发新请求，最后一次返回后再次核对截止时间，单HTTP完整正文15秒上限不变。业务策略没有真实外部地址覆盖或自动重试开关，测试仅通过包内构造器访问自有回环HTTP。
- 手机/邮箱/头像区分“字段未返回或null”与“实际返回空串”；缺失字段如何更新本地仍等待已发问题的答复，本轮没有实施覆盖或清空本地数据的政策。多部门主部门只保留管理员选择，未自动选取；姓名和部门名称超出本地字段容量时，后续预览必须报冲突，不静默截断。
- 加密封装复用独立IM密钥及SNAPSHOT用途隔离，包含固定格式版本、确定性序列化和SHA-256摘要。解密同时核验租户、配置、版本、企业及应用，拒绝多余/重复字段、类型强转、错误摘要、错误主密钥、错误配置及篡改载荷。普通封装序列化仅返回摘要，诊断文本不含人员字段。最大明文8MiB、密文12MiB，继承既有加密组件限额。
- 尚未接入`sys_im_sync_run`持久化、差异预览、确认摘要、分批应用/恢复、新用户零角色分配、映射与安全禁用、同步操作页面或1783—1785菜单。七个新类正常装配后外部接入仍停用，没有对本地员工、部门或映射写入。

本轮接口采用已核实的企业微信官方文档：`https://developer.work.weixin.qq.com/document/path/90201`、`https://developer.work.weixin.qq.com/document/path/90208`、`https://developer.work.weixin.qq.com/document/path/90227`。当前成员列表只取本部门，不使用SDK旧实现的`fetch_child`参数，也不虚构cursor分页；返回未知分页标志直接拒绝。官方对新应用敏感联系字段返回有限制，不假造字段齐全。
