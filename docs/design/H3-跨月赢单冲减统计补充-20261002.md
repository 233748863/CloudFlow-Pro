## 已裁决的范围

冲减 = 撤回赢单时，用一笔反向记录扣回原赢单金额和数量。以下示例为9月赢单10,000.00元，甲60%、乙40%，10月全部撤回；币种均为CNY，期间没有其他业务。

| 字段或行为 | 方案A：撤回当月扣回，保留原月结果（已批准、已实现） | 方案B：回到原赢单月份扣回（未采用） |
| --- | --- | --- |
| 9月甲/乙赢单金额 `wonAmount` | 仍为6,000.00 / 4,000.00 | 查询时重算为0.00 / 0.00 |
| 10月甲/乙赢单金额 `wonAmount` | -6,000.00 / -4,000.00 | 本次撤回不计10月金额 |
| 参与赢单数量 `wonOpportunityCount` | 9月各+1；10月各-1 | 9月各归零；10月不计本次扣回 |
| 比例权重数量 `allocatedWonCount` | 9月+0.6000 / +0.4000；10月-0.6000 / -0.4000 | 9月各归零；10月不计本次扣回 |
| 同部门多人参与 | 每笔赢单在该部门只计一次参与数量；撤回同样只扣一次 | 在原月份去除该笔部门参与数量 |
| 9—10月合计 | 原事实与冲减相抵为零 | 原月份已经归零，合计为零 |
| 历史重查与页面说明 | 10月允许负数，解释为当月撤回旧赢单；原9月统计不因10月撤回改变 | 原9月结果随后续撤回变化，页面必须说明历史已重算 |

两方案均按原冻结人员、部门、金额及比例扣回，后续调岗或团队调整不改变该来源；撤回后再次赢单产生新事实，按新事实自己的人员和发生月份纳入。相同来源重复投递不得重复扣回。金额和数量的月份保持一致，不能金额记10月而数量回改9月。

本次不调整OWNER_V1旧口径、阶段漏斗的历史队列口径、已批准的回款考核或实际发薪规则，也不把合同履约报表的实时口径扩展为销售业绩的历史口径。客户数和跟进数仍按各自原业务归属计数；期初快照继续单列，不能补造旧赢单事件。合同金额必须来自实际合同事实，不能用赢单金额代替。
