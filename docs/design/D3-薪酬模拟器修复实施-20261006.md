# D3薪酬模拟器修复实施

实际故障证据为B105/F63名称R2中的`simulator-baseline.json`：页面填写10000.01元并提交，接口返回500。旧页面与服务端请求、返回字段不一致，服务端也未落实已有DTO约定的员工基准和结构成员。

## 本次修复范围

沿用现有模拟接口与表结构，只读测算，不生成工资或修改员工薪资。页面发送服务端已有的员工、薪资结构、薪级、逐项覆盖金额、社保缴费基数及比例、专项扣除；金额用十进制文本完整传递，结果读取现有`gross/socialPersonal/personalTax/breakdown`等字段。

员工基准取当天已生效的最新薪资分配，按现有数据权限检查员工；结构和薪级只接受当前租户的启用记录，组成只读取结构的`componentConfig.itemIds`。覆盖金额优先，随后取员工已有组成，缺少基本工资时才使用薪级中位值；已有组成只有总额时沿用当前工资单的基本工资含义，要求结构存在唯一的基本工资项目，不能自行拆分至多个项目。组件编号与代码均按现有薪资快照规则识别，冲突、结构外项目和无法匹配的基准明确拒绝。

显式覆盖0元保持0元。公司成本单列明细，不计入员工收入；扣减项按原模拟公式扣减，社保个人额和个税按原月度估算规则计算。校验负金额、超过工资金额容量、错误费率及无效税率配置；地区参数尚无既有计算实现，收到地区要求时明确提示不支持，避免只回显地区而误示已按地区计算。

本功能继续使用既有模拟参数和月度税率字典，页面显示起征额、个人缴费比例和专项扣除，明确“月度估算，仅供比较；正式工资以薪资批次及财务核定税表为准”。本次不核定或替换2026正式税率。
