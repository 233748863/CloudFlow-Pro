# C3代理归还响应接续

产品仍为B77/F50；上一轮附件/预览/引用R75、相邻R78、汇总R1已通过，本轮继续AC-3最后开放的动作返回及统一范围核对。

新增`verify-c3-action-returns.mjs`与`--action-returns`/`-ActionReturns`专用入口。两份流程分别使用AGENT与AGENT_ASSIST，由本轮原负责人通过本人接口建立限定定义范围的代理设置，真实发起后验证代理读取、归还响应、归还后办理拒绝、原负责人完成及历史读取。隐藏顶层字段与两行子表金额，发布后更新表单验证固定旧版本；专项不直接写数据库、不清Redis，finally通过本人接口停用并重读确认设置。

现有归还操作会保存AGENT_RETURN历史。因此归还人失去当前待办办理权限，仍可按历史参与人身份读取实例，且必须应用原节点字段规则；不得把所有后续读取均403作为预期。动作响应WfTask按当前源码仅返回任务列，非持久化variables未赋值，实际返回仍须检查。
