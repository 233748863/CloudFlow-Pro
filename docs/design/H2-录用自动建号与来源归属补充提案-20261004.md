# 录用自动建号与来源归属补充提案

状态：待用户确认新增账号来源字段及自动账号生成规则；本提案尚未修改业务源码、正式建表脚本或运行库。原姓名100字符、联系方式完整保留的批准继续有效。

## 已核实的问题

正式`hr_offer.offer_no`允许60字符，`sys_user.user_name`最多30字符。`HrWorkflowCallbackServiceImpl.buildUserName`将完整录用编号转小写、替换符号后直接用作账号，31—60字符编号无法可靠完成建号；中文或符号不同的编号还可能转成相同账号。

`ensureUserAccount`目前只凭生成的用户名复用已有账号，没有核验该账号是否由同一录用创建。账号创建由认证服务独立提交，人事随后失败时需要重试，因而仅禁止一切重名复用也不能满足故障恢复要求；需要记录可信的录用来源。

历史实际录用5022、标记`bea97d66cf83`的审批已通过。首轮因多人审批回写校验遗漏失败，B58已修正；原消息25107重放又被自有测试租户名额拒绝，原单仍未恢复。之后的组合使用23字符新编号通过，未验证原32字符编号。这些失败历史继续保留。

## 拟实施的业务行为

自动录用建号统一生成`offer_`加系统录用ID，例如`offer_5022`；正整数ID最多19位，自动账号最多25字符。业务录用编号仍允许60字符并原样保存，姓名最多100字符、手机号及邮箱沿用已批准容量，不截断任何业务信息。已有账号名称和手工建号规则保持原值。

同一租户、同一录用的重试只能取得最初创建的账号，不重复占用名额、不新增账号，也不覆盖已建账号的姓名、联系方式、密码或角色。其他人手工创建的同名账号不视为该录用的账号；明确提示冲突并保留原账号，禁止自动建立员工关联。来源账号已删除或停用时同样提示人工核查，不自动恢复启用。

账号在认证服务已提交、人事档案尚未提交时，原审批消息可通过现有管理入口重试；重试按来源取回原账号，继续完成原录用。已成功的重复消息继续沿用原回调去重逻辑。

## 具体结构与接口

在既有`sys_user`增加一列和一个唯一索引，不增加表：

```sql
hr_offer_id BIGINT(20) DEFAULT NULL COMMENT '由人事录用自动创建账号的来源录用ID',
UNIQUE KEY uk_user_hr_offer (tenant_id, hr_offer_id)
```

普通账号该列为空；仅认证服务的录用专用创建入口可写一次。通用用户创建、编辑、导入和账号更新接口不接受或覆盖该字段，外部用户接口不返回该内部来源字段；不通过昵称、邮箱、手机或用户名猜测来源，不事后给既有账号补写来源。

新增受既有人事服务身份限制的`POST /inner/auth/user/from-offer`。人事在真实录用审批结果校验通过后传入来源录用ID及原有必要建号资料；认证服务从当前可信上下文确定租户，自行生成账号名，校验正整数来源ID，按来源查询并在同一事务中创建账号及保存来源。来源和用户名唯一约束处理重复/并发请求；只有同来源记录可作为成功重试结果，用户名冲突必须拒绝。初始密码、首次修改密码、岗位角色和租户名额继续走原规则。

人事回调改为调用此专用入口，取消按用户名直接复用账号。旧已成功录用依靠原回调执行标记保持不重跑；遇到没有来源依据的历史半完成账号，保留冲突与人工核查提示，不自动认领。

项目未上线，按既有约定直接修改正式01脚本并重建07演示数据，不提供生产迁移脚本。自有运行库的结构准备须先核对归属，前后验证全部既有账号字段及行数保持；正式环境不操作。

## 验证及恢复范围

独立检查覆盖30/31/60字符录用编号、100字符姓名及完整联系方式、符号和中文编号、最大正整数来源ID、非法来源、跨租户、普通接口伪造来源、停用/删除账号、同名不同来源、同来源重复与并发。实际数据库检查使用真实事务和唯一约束，不以字符串生成测试代替账号归属检查。

实际平台恢复原录用5022及原失败消息25107，只临时为明确归属的测试租户预留一个建号名额，随后恢复原额度；原审批、录用编号、候选人、推荐、消息和历史保持。再通过正常业务入口验证长编号新录用、人事失败后的原消息恢复及重复提交，核对一个来源仅一个账号和一份员工档案；不得手工把原业务状态写成成功。

完成完整后端构建、身份与录用邻接检查、真实审批建号、原工作流及当前版本关联验收后，更新实施记录和全量索引；全35份PRD/681条仍按原完整目标推进。

## 需要确认的范围

确认将自动录用账号改为最长25字符的系统ID形式，以及增加上述来源列、唯一索引和专用内部入口。依据《04-编码任务通用约束》第六节第3条：“需要新增设计文档未提到的表或字段 —— 说明为什么需要。”本列用于区分同来源安全重试与无来源的同名账号，现有姓名及联系方式容量批准未包含它。
