## 实施约束

同一会话的在途身份读取共用请求，完成后不缓存身份或权限；登录、退出和切换租户使此前的身份读取失效。旧身份请求返回401时不能清除新会话，成功响应也不能回填旧身份；真实当前会话失效仍清理并退出。初始化遇到暂时故障时隐藏业务页面、保留登录凭据，明确提示后由用户重试；已有身份的刷新暂时失败不清除当前会话。

界面复用现有结果页、语义色、字体和按钮；不增加新依赖或动画，重试触控区至少44px，电脑和手机采用同一布局。

```text
┌─────────────────────────────┐
│       身份验证暂不可用       │
│   当前无法读取登录信息       │
│     [重新验证] [退出登录]     │
└─────────────────────────────┘
```

当前已接通身份请求复用、内存会话版本、初始化卸载保护，以及登录/退出/切租户的旧响应隔离。请求拦截器对HTTP401和业务401均核验发起时的会话版本；新会话不会受上一会话的401去重计时影响。初始化的409、503、断网、空成功及缺少身份字段均进入人工重试页，不自动重试，不开放业务数据。
