# 离职结算借款来源接线

复用现有借款台账核验，新增只读`HrSettlementAdvanceSource`。它自行读取同租户、授权员工的封存未付工资和真实已放款借款，对每条工资预扣明细与实际预约双向匹配，核对金额、工资月份、业务事件、员工及租户。本结算应收本金为实际未还本金减本次导入工资已预扣的本金；本结算自身的预约仅验证，不再扣减一次。完全被工资预扣的借款保留零金额来源，供以后入账时追踪；实际已还与已核销部分不再收取。

其他结算占用、未纳入本结算的工资预约、缺预约、来源类型/编号/金额不一致、余额与流水不一致、放款日期晚于离职、跨员工/租户来源均明确报缺项。工资含尚未实际支付的借款退回时，提示先完成工资补正再核定本金；目前未实现将尚未退回的本金预先预约。该检查没有写入预约、实际还款或改写工资，没有新增数据库字段、对外接口或菜单。
