# H2离职结算确认、收付及来源入账

沿用已批准设计：独立财务审批通过后，人事或财务确认原金额；正净额建立唯一OA付款，实际付款通知核实后入账；零净额保存抵销事实后入账；负净额由财务上传私有凭据并登记实际收款日期后入账。工资预扣与结算剩余本金分别按原来源入账，同一事务处理工资、借款、原单位假期及培训追偿。金额、原审批与原台账均保留。

## 页面设计

沿用superdesign及现有结算对话框、语义主题变量、字体和4px间距。电脑两列、手机单列，操作区域至少44px；控件150ms反馈，尊重减少动画设置。确认和收款均显示固定方向、金额及明确确认选项；响应不确定时保留输入，锁住再次提交，通过读取原单恢复。

```text
+ 离职结算详情 -----------------------------------+
| 员工 / 结算状态 / 审批结果                       |
| 应付 / 补偿 / 应收 / 损失 / 本单净额             |
| 收付进度：待确认 / 待付款或收款 / 已结清         |
| 付款编号或收款凭据 / 实际日期 / 确认时间         |
| 来源明细及原核定依据                            |
| 重新读取 / 确认结算 / 登记收款 / 核对并关闭      |
+------------------------------------------------+
| 收款窗口：固定金额 / 实际日期 / 私有凭据         |
| 凭据上传状态 / 失败保留输入 / 读取已保存结果     |
+------------------------------------------------+
```

审批、确认及收付各自展示状态，收付款完成后另核对全部资产责任及来源入账才能关闭。资产损失核定只确认金额，关闭仍须OA真实完成归还或损失处置。
