## 3. 失败和纠正

- 规则R1：13个既有驼峰权限被错误拒绝；修正大小写支持，不改原权限码或五类前缀，R2/R3通过。
- 数据库R1：JSON文本`null`被解码成空对象引用，没有按非法覆盖拒绝；修正为显式拒绝，R2/R3通过。后续再明确禁止小数和指数形式配额被自动截断为整数。
- 生成器R1：表数断言仍为357，发现实际360后正确停止；更新为批准新增3表后的360，并补三表排除和租户四列NULL策略，R2通过。
- 契约R1：新测试误引用不存在的`clean`变量；改为独立克隆的基线对象，R2通过。失败日志不删除，不把它描述为生产权限问题。
- 空库日志的三次`ERROR 3819`来自旧门户演示保护的预期拒绝用例，随后均有对应`PASS`及整体退出0；没有把初始化失败当成成功。
