## 关键业务口径

SLA = 工单承诺响应及解决时限；工作时间模式只累计日历中的工作时段。ROI =（归因回款 − 实际成本）÷ 实际成本。

| 项目 | 实施要求 |
| --- | --- |
| 活动状态 | `PLANNED / IN_PROGRESS / COMPLETED / CANCELLED / NOT_HELD` |
| 接受状态 | `NONE / ACCEPTED / DECLINED / TENTATIVE` |
| OA/H4 | OA 当前缺少上述两个状态字段；经用户批准，CRM 采用 E/H4 共同标准，OA 补字段及双方一致性联验留 H4，本次未修改 OA 日程 |
| 工单映射 | `CRITICAL → P1`、`HIGH → P2`、`MEDIUM → P3`、`LOW → P4`；共用的 `severity_level` 字典不变 |
| 资质与转化 | 人工资质仅四值；已转化是销售阶段及漏斗独立分类，不加入人工资质下拉框 |
| 金额与单位 | 金额 `DECIMAL(16,2)`；SLA 整数分钟；营销九项计数；ROI `DECIMAL(20,4)`，成本为零时 `NULL` |
| 币种 | 按 E3 本期单币种要求，仅支持人民币 `CNY` 的额度申请、占用和营销回款归因；其他币种明确拒绝，不做汇率换算 |
| 时间线 | 六表 `UNION ALL` 后统一排序分页；不新增冗余事件表、不增加缓存、不做各表 TOP N 截断 |
| 名单与审批 | 预览脱敏，原始导出独立权限；金额调整审批期间旧额度有效；陈旧流程实例不能覆盖当前审批 |

五个新增任务全部注册在 `sys_job`，处理器落在 `CrmCustomerOperationsJobs`：

| `crmCampaignRevenueRecalc` | 每日 04:00 | `ENABLED` |

```powershell
Push-Location cloudflow-backend
```

```powershell

node node_modules/vite/bin/vite.js preview --host=127.0.0.1 --port=4188 --strictPort
```
