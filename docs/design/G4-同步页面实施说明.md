# G4同步页面实施说明

本页承接已批准的组织同步设计，仅展开范围配置、预览和记录交互，不改变停用、角色、套餐及待确认业务规则。

```text
+---------------------------------------------------+
| 企业微信组织同步                 [刷新] [生成预览] |
| 配置选择 / 部署状态 / 本地根 / 远端部门范围         |
| 仅预览，不写组织；缺失字段和调出范围仍待确认        |
+---------------------------------------------------+
| 历史记录：时间 / 配置版本 / 完整性 / 状态 / 查看    |
+---------------------------------------------------+
| 预览报告：拟新增 / 拟更新 / 拟停用 / 冲突           |
| 部门、成员：原值 -> 预期值 / 冲突原因 / 分页        |
+---------------------------------------------------+
```

手机按相同顺序改为单列卡片，沿用项目字体、浅色/深色语义色和共用弹窗/下拉框/分页；操作区域至少44px，按钮反馈150ms，尊重减少动画设置。预览请求期间禁止重复提交，结果不确定时先读历史记录，禁止自动重试；身份或套餐撤回时清除报告。配置编辑增加范围选择，员工主部门由管理员明确指定，不自动选择第一个。

为避免要求管理员手输部门编号或额外购买部门管理页面，范围候选使用现有`system:im:config:manage`权限：本地部门分页只返回编号、父编号和名称，远端部门由显式操作读取已保存并启用配置的授权范围。候选请求不写组织、不存成员信息，不新增权限码或数据表；外部读取前后核验当前身份、套餐和配置版本。正式预览/记录权限仍为1783/1785，1784执行未实现前不开放。
