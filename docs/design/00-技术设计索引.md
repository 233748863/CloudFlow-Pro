## 设计过程中新发现的 PRD 偏差（摸排之外的 4 处）

摸排阶段已发现 11 处（见 `docs/prd/B-H-存量摸排报告.md`）。**写技术设计时对着代码核规范，又发现 4 处**：

| # | 发现 | 影响 |
| --- | --- | --- |
| 1 | **`aggregate_type` 用法错**：A2 的 PRD 写"按 `aggregate_type='MESSAGE'` 区分"，实测 `OutboxPublisher` 存的是 `sourceModule` | 改为用 `event_type="MESSAGE_SEND"` 区分（A-03 §0） |
| 2 | **批次 A 表数算错**：A2 的 PRD 写"244→245"，只算了自己的 5 张表 | 批次 A 整体 +12−4，实际 252（A-01 §6） |
| 3 | **`ProjectExecutionStateService` 已实现进度自动计算**：F3 的 PRD 写"进度靠手填"，实测已按任务+里程碑完成数比例算 | `TASK_COMPLETION` 模式已有，只需补 `TASK_PROGRESS` 加权模式（F §0.1） |
| 4 | **SYS-04 越权面定位有误但问题更实**：G3 的 PRD 写"url 是直链"，实测有服务端访问端点，但**只需 `system:file:list` 权限即可访问本租户任意文件**（无业务级校验） | 核心价值从"改签名 URL"改为"加业务级权限校验"，需注册 17 个 `FileAccessChecker`（G §0.1） |

**累计 15 处 PRD 偏差**（摸排 11 + 设计 4）。

## 跨批次的强约束（实现时必须遵守）

| # | 约束 | 涉及 |
| --- | --- | --- |
| 1 | **引擎内部数据不过滤**：条件分支求值、审批人解析用 `getRawVariables()`；只有对外响应用 `getVisibleVariables()` | C §5.2 |
| 2 | **表达式解析器全系统一套**：C3 建 `RestrictedExpressionEvaluator`，H2 的绩效公式复用其 `evalNumeric`，禁 eval | C §5.3、H §3.4 |
| 3 | **活动模型取值对齐**：E1 的 `crm_activity` 定标准，H4 的 OA-07 必须用同一套 `status` 与 `acceptance_status` | E §1.2、H §3.1 |
| 4 | **日历归属统一解析**：D1/D2/E2 都调批次 A 的 `resolveCalendarId()` 三级回退，不各自实现 | A-03 §3.1 |
| 5 | **台账模式统一**：D1 假期、H4 耗材都是"台账为真相源 + 物化值为读模型"，禁止就地改数 | D §1.5、H §3.2 |
| 6 | **金额全程 DECIMAL**：折旧、薪资、工时双轨、子表合计不用浮点 | D/F/C |
| 7 | **权限码前缀限五类**：`system`/`oa`/`crm`/`hr`/`workflow` | 全批次 |
| 8 | **禁 Java 拼 SQL**：查询走 `LambdaQueryWrapper` 或 XML mapper | 全批次 |
| 9 | **文件访问必过 `FileAccessChecker`**：未注册的 `biz_type` 默认拒绝 | G §1.3 |
| 10 | **模块 DDL 规范不同**：workflow 用 `VARCHAR(64)` 主键无 `deleted`；CRM/HR/OA 用 `BIGINT` 自增有 `deleted`；common 列宽 17、CRM 列宽 18 | 全批次 |

## 建议的实施顺序与关键路径

```
批次 A（基础设施地基，5 项一次性交付）
  ├─ A1 代码生成器（本批先行，后续新表 CRUD 由它产出）
  ├─ A2 消息中心（含存量六套收口，21 个调用方改造）
  ├─ A3 任务平台（集中调度 + 异步协议）
  ├─ A4 节假日日历 ★ 被 D1/D2/E2/H2 四处依赖
  └─ A5 图表库 ★ 被全部报表依赖
        ↓
批次 B（工作流语义）    ← 可与 C 并行
批次 C（表单能力）      ← M0 注册表重构是成败关键
        ↓
批次 D（HR 规则精度）   ← 依赖 A4 日历；D1→D2→D3 顺序不可乱
批次 E（CRM 客户经营）  ← 依赖 A4（SLA 计时）、A5（报表）；E5-b 阻塞
批次 F（OA 深度）       ← F2→F5 顺序（供应商准入是询价前提）
        ↓
批次 G（体验与集成）    ← G3 的 M3（17 个校验器）需等 D/E/F 建表完成
        ↓
批次 H（按需挑选）      ← 建议只做 4 项：INT-06 一期、WF-11、OA-08、HR-09
```

**关键路径**：A4 日历 → D1 请假天数 → D2 考勤判定 → D3 薪资算款
**最长阻塞**：G3 的文件权限校验器要等 D/E/F 都建完表
