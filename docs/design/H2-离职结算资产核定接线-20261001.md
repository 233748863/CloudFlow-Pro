# H2离职结算资产核定接线

沿用已批准设计中的HR核定资产损失。复用结算编辑权限、明细快照及OA调拨事实，不新增表或菜单。保管与领用归属冲突先在OA处理；HR不能靠核定损失改写OA责任人。

逐项核定分为损失扣款、责任已解除且不扣款、撤销旧核定。损失金额大于零、至多999999999999.99元，逐项四舍五入到分并保留输入值；零扣款必须由服务器读到OA已解除该员工责任及真实已完成处置，展示RETURN/TRANSFER/SCRAP/DISPOSE/LOST实际类型，不将它们统一标为归还。核定原因必填，身份、时间由服务器记录；重算核对资产及处置版本，变化后保留原金额和核定历史，但标为待重新核定。资产离开未归还清单时仍保留本单原行并核对具体资产，读取失败不能当作已完成。实际闭单还须复验责任解除，不由本次草稿核定代替。
