# 车辆管理系统设计与操作文档

## 1. 系统概述
车辆管理系统旨在为企业提供全面的公务用车管理解决方案，包括车辆档案管理、用车申请与审批、用车记录、费用统计等功能。

### 1.1 核心功能
*   **车辆管理**：维护车辆的基本信息（车牌、型号、状态等）。
*   **用车申请**：员工提交用车申请，支持选择可用车辆，系统自动检测冲突。
*   **审批流程**：集成工作流引擎，支持多级审批。
*   **费用管理**：记录每次用车的相关费用（油费、过路费等），并提供统计报表。

## 2. 数据库设计

### 2.1 车辆信息表 (sys_vehicle)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| vehicle_id | BIGINT | 主键 |
| license_plate | VARCHAR | 车牌号 |
| status | CHAR(1) | 1:可用, 2:已预约, 3:使用中, 4:维修中, 5:报废 |
| mileage | DECIMAL | 当前里程 |

### 2.2 用车申请表 (sys_vehicle_usage)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| usage_id | BIGINT | 主键 |
| vehicle_id | BIGINT | 车辆ID |
| applicant_id | BIGINT | 申请人ID |
| start_time | DATETIME | 开始时间 |
| end_time | DATETIME | 结束时间 |
| status | CHAR(1) | 0:待审批, 1:已批准, 2:已驳回, ... |

### 2.3 费用记录表 (sys_vehicle_expense)
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| expense_id | BIGINT | 主键 |
| vehicle_id | BIGINT | 车辆ID |
| amount | DECIMAL | 金额 |
| expense_type | VARCHAR | 1:油费, 2:过路费, ... |

## 3. 接口定义 (API)

### 3.1 车辆管理
*   `GET /vehicle/list`: 分页查询车辆列表
*   `POST /vehicle`: 新增车辆
*   `PUT /vehicle`: 更新车辆信息
*   `DELETE /vehicle/{ids}`: 删除车辆
*   `GET /vehicle/available`: 获取当前可用车辆

### 3.2 用车申请
*   `POST /vehicle/usage`: 提交用车申请
*   `GET /vehicle/usage/list`: 查询申请记录

### 3.3 费用管理
*   `POST /vehicle/expense`: 录入费用
*   `GET /vehicle/expense/list`: 查询费用明细
*   `GET /vehicle/expense/stats`: 获取费用统计

## 4. 操作手册

### 4.1 车辆档案管理
1.  进入 **车辆管理** 页面 (`/admin/vehicle/list`)。
2.  点击 **新增车辆**，填写车牌、品牌、载客量等信息。
3.  可在列表中对车辆进行 **编辑** 或 **删除**。
4.  更改车辆状态（如维修中）会影响该车辆的可预约性。

### 4.2 申请用车
1.  进入 **公务车预约** 页面 (`/admin/vehicle/booking`)。
2.  选择所需的车辆（仅显示可用车辆）。
3.  填写开始/结束时间、目的地、事由及随行人员。
4.  点击 **提交申请**。系统会自动检测该车辆在指定时间段是否已有预约，若有冲突将提示失败。
5.  提交成功后，申请状态为“待审批”。

### 4.3 审批与调度 (管理员)
1.  管理员在 **工作流待办** 中查看申请。
2.  审批通过后，申请状态变为“已批准”。
3.  车辆状态在实际使用期间应更新为“使用中”（此功能可通过调度任务或人工更新实现）。

### 4.4 费用录入与统计
1.  进入 **用车记录与费用** 页面 (`/admin/vehicle/usage`)。
2.  在“用车记录”标签页，找到已完成的行程，点击 **录入费用**。
3.  填写费用类型、金额、日期等。
4.  在上方统计区域可查看总费用及笔数统计。

## 5. 后续扩展建议
*   **移动端适配**：开发H5或小程序端，方便司机实时打卡和录入费用。
*   **GPS集成**：接入车载GPS数据，自动更新里程和位置。
*   **定期保养提醒**：基于里程或时间自动生成保养任务。
