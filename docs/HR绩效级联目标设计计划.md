# HR绩效级联目标设计计划

## 纠偏口径

ABCD、A类/B类/C类/D类只作为示例名称，不是固定枚举；系统必须支持N个业务自定义考核类型，并允许每个类型继续挂载N个统计指标。

考核类型 = 业务自定义的目标分类，例如“核心商品”“新品”“区域客户”“重点项目”；指标 = 一个独立统计口径，例如“销售额”“销售量”“签约数”“交付件数”；单位 = 指标数值展示和录入单位，例如“元”“件”“个”“单”，由用户自定义；数值类型 = 指标录入约束，支持小数、整数、百分比和0-4位小数精度。

## 目标模型

1. 目标计划：周期、目标名称、考核类型集合、指标集合、计分封顶、审批状态。
2. 考核类型：`categoryCode`、`categoryName`，数量不设固定上限，由业务创建。
3. 指标：`metricCode`、`metricName`、`metricUnit`、`valueType`、`precision`、`metricWeight`，数量不设固定上限，`metricWeight`是默认权重。
4. 类型指标：`categoryCode + metricCode + metricWeight`，权重作用在最终统计项上。
5. 归档快照：结果审批通过时固化目标、实际值、原始达成率、封顶得分、等级和完整分解树，后续查询归档结果优先读取快照。

## 级联分解

总目标 → 部门目标 → 考核类型 × 指标目标 → 员工个人目标。

同一个员工在同一绩效周期下可以同时承接N个叶子目标，例如“核心商品-销售额-100000元”和“核心商品-销售量-300件”；每个叶子目标独立填报实际完成值，独立计算达成率。

## 达成率

单项达成率 = 实际完成值 / 目标值 × 100%。

综合达成率 = Σ(类型指标达成率 × 类型指标权重) / Σ(类型指标权重)，按“考核类型 × 指标”维度汇总后计算；计分封顶只影响封顶后得分，不覆盖原始达成率。

## 验收标准

1. 新建绩效目标时可新增N个考核类型，不出现固定ABCD限制。
2. 新建绩效目标时可新增N个指标，每个指标可输入自定义单位和权重。
3. 个人目标可按“考核类型 × 指标”形成多条任务，销售额、销售量、数量类指标分别统计，综合达成率按类型指标权重计算。
4. 空部门计划禁止提交，计划阶段禁止写入实际完成值，实绩只允许员工叶子任务填报。
5. 绩效调薪必须来自已归档绩效，按员工绩效分校验最低分，并限制同一目标同一员工重复生成。
