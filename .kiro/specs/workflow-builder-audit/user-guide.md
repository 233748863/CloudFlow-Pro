# 流程设置功能用户指南

## 概述

流程设置功能允许您为工作流配置详细的元数据信息，包括描述、分类、标签和关联表单，帮助更好地管理和检索流程。

---

## 功能入口

### 打开流程设置

1. 进入流程设计器
2. 在顶部工具栏找到"流程设置"按钮（蓝色图标）
3. 点击按钮打开流程设置对话框

![流程设置按钮位置](位于"模板库"和"全局属性"之间)

---

## 功能说明

### 1. 基本信息（只读）

**流程名称** 和 **流程Key** 在此处以只读方式显示，如需修改请在工具栏顶部的输入框中编辑。

- **流程名称**: 流程的显示名称，用于在列表中识别流程
- **流程Key**: 流程的唯一标识符，用于系统内部引用

### 2. 流程描述

**用途**: 详细说明流程的用途、适用场景和注意事项。

**如何使用**:
1. 在"流程描述"文本框中输入描述内容
2. 支持多行文本，最多 65535 字符
3. 建议包含：
   - 流程用途
   - 适用场景
   - 使用注意事项
   - 特殊要求

**示例**:
```
员工请假审批流程，支持病假、事假、年假等多种请假类型。

适用场景：
- 所有员工申请各类假期
- 需要部门经理审批

注意事项：
- 请假天数超过3天需要提前申请
- 病假需要提供医院证明
```

### 3. 流程分类

**用途**: 将流程归类到特定的业务领域，便于管理和检索。

**可选分类**:
- 未分类
- 行政办公
- 财务管理
- 人事管理
- 销售业务
- IT运维
- 生产制造
- 质量管理
- 项目管理
- 其他

**如何使用**:
1. 点击"流程分类"下拉菜单
2. 选择最符合的分类
3. 如果没有合适的分类，选择"其他"

**建议**: 选择合适的分类可以帮助用户快速找到相关流程。

### 4. 流程标签

**用途**: 为流程添加关键词标签，支持多维度检索。

**如何添加标签**:

**方法 1: 手动输入**
1. 在标签输入框中输入标签名称
2. 按回车键或点击"添加"按钮
3. 标签会显示在已添加列表中

**方法 2: 快捷选择**
1. 在"常用标签"区域找到合适的标签
2. 点击标签名称（如"审批"）
3. 标签会自动添加到已添加列表

**如何删除标签**:
1. 在已添加的标签上找到 × 按钮
2. 点击 × 按钮删除标签

**常用标签**:
- 审批、请假、报销、采购、合同
- 入职、离职、培训、考勤、绩效
- 项目、任务、变更、发布、维护

**注意事项**:
- 标签不能重复
- 空标签不会被添加
- 建议添加 2-5 个标签
- 标签应简洁明了

### 5. 关联表单

**用途**: 将流程与特定的表单关联，流程启动时使用该表单收集数据。

**如何使用**:
1. 点击"关联表单"下拉菜单
2. 等待表单列表加载完成
3. 选择要关联的表单
4. 如果不需要关联表单，选择"无"

**注意事项**:
- 表单列表会自动从系统加载
- 如果加载失败，会显示错误提示
- 可以随时更改或取消关联
- 关联表单后，流程启动时会要求填写该表单

## 操作流程

### 创建新流程时配置

1. **创建流程**
   - 点击"新建流程"按钮
   - 进入流程设计器

2. **配置基本信息**
   - 在顶部输入流程名称和 Key

3. **打开流程设置**
   - 点击"流程设置"按钮

4. **填写流程信息**
   - 输入流程描述
   - 选择流程分类
   - 添加流程标签
   - 选择关联表单（可选）

5. **保存设置**
   - 点击"保存设置"按钮
   - 设置会立即生效

6. **设计流程**
   - 添加和配置流程节点

7. **保存流程**
   - 点击"保存"按钮
   - 所有配置会一起保存到后端

### 编辑现有流程时修改

1. **打开流程**
   - 从流程列表中选择要编辑的流程
   - 点击"编辑"按钮

2. **查看当前配置**
   - 点击"流程设置"按钮
   - 查看已有的配置信息

3. **修改配置**
   - 修改描述、分类、标签或表单
   - 点击"保存设置"

4. **保存流程**
   - 点击"保存"按钮
   - 修改后的配置会更新到后端

## 使用技巧

### 1. 编写好的流程描述

**好的描述**:
```
员工请假审批流程

用途：处理员工的各类请假申请
适用人员：所有正式员工
审批流程：员工申请 → 部门经理审批 → 完成

注意事项：
1. 请假天数超过3天需要提前申请
2. 病假需要提供医院证明
3. 年假需要提前一周申请
```

**不好的描述**:
```
请假流程
```

### 2. 选择合适的分类

- 根据流程的主要业务领域选择
- 如果流程涉及多个领域，选择最主要的
- 使用标签来补充其他维度的分类

### 3. 添加有效的标签

**好的标签**:
- 请假、审批、人事
- 报销、财务、费用
- 采购、合同、供应商

**不好的标签**:
- 流程、系统、管理（太宽泛）
- 员工请假审批流程（太长，应该拆分）

### 4. 关联表单的最佳实践

- 为每个流程创建专用的表单
- 表单字段应与流程需求匹配
- 定期检查表单是否还在使用

## 常见问题

### Q1: 流程设置是必填的吗？

**A**: 不是。流程描述、分类、标签和关联表单都是可选的。但建议至少填写描述和分类，以便更好地管理流程。

### Q2: 可以不保存设置直接关闭吗？

**A**: 可以。如果点击关闭按钮或点击对话框外部，未保存的修改会丢失。

### Q3: 修改流程设置后需要重新发布吗？

**A**: 不需要。流程设置的修改会在保存流程时一起提交，不需要重新发布。

### Q4: 标签有数量限制吗？

**A**: 没有硬性限制，但建议添加 2-5 个标签。太多标签会降低检索效率。

### Q5: 可以创建自定义分类吗？

**A**: 目前不支持。如果现有分类不满足需求，可以选择"其他"并使用标签来补充说明。

### Q6: 关联表单后可以更改吗？

**A**: 可以。随时可以更改或取消关联。但注意，已启动的流程实例不会受影响。

### Q7: 表单列表加载失败怎么办？

**A**: 检查网络连接和后端服务状态。如果问题持续，可以先保存流程，稍后再关联表单。

### Q8: 流程描述支持富文本吗？

**A**: 不支持。流程描述是纯文本，不支持格式化。

## 注意事项

### 1. 数据安全

- 流程描述和标签会存储在数据库中
- 不要在描述中包含敏感信息
- 标签应使用通用的关键词

### 2. 性能考虑

- 流程描述不要过长（建议 500 字以内）
- 标签数量不要过多（建议 2-5 个）
- 表单列表加载可能需要几秒钟

### 3. 兼容性

- 旧版本的流程可能没有这些配置
- 编辑旧流程时，配置字段会显示为空
- 可以随时为旧流程添加配置

## 示例场景

### 场景 1: 请假审批流程

**流程名称**: 员工请假审批

**流程Key**: leave-approval

**流程描述**:
```
员工请假审批流程，支持病假、事假、年假等多种请假类型。

适用场景：
- 所有员工申请各类假期
- 需要部门经理审批

注意事项：
- 请假天数超过3天需要提前申请
- 病假需要提供医院证明
```

**流程分类**: 人事管理

**流程标签**: 请假、审批、考勤

**关联表单**: 请假申请表

### 场景 2: 报销审批流程

**流程名称**: 费用报销审批

**流程Key**: expense-reimbursement

**流程描述**:
```
员工费用报销审批流程，支持差旅费、办公费、招待费等。

审批流程：
1. 员工提交报销申请
2. 部门经理审批
3. 财务审核
4. 出纳付款

注意事项：
- 需要提供发票原件
- 报销金额超过1000元需要总经理审批
```

**流程分类**: 财务管理

**流程标签**: 报销、财务、费用

**关联表单**: 费用报销单

### 场景 3: 采购审批流程

**流程名称**: 采购申请审批

**流程Key**: purchase-approval

**流程描述**:
```
物资采购审批流程，支持办公用品、设备、服务等采购。

审批规则：
- 金额 ≤ 5000元：部门经理审批
- 金额 > 5000元：部门经理 + 总经理审批

注意事项：
- 需要提供供应商报价单
- 紧急采购需要说明原因
```

**流程分类**: 财务管理

**流程标签**: 采购、审批、供应商

**关联表单**: 采购申请单
